# KubeJS Visual Editor
<br />
<ul>
<li>When using this application, you will start on the recipe create page, here you can search items and drag them into the recipe layout to create a recipe.</li> <br />
<li> You can change the recipe type from a secondary sidebar, and change input/output amounts via number inputs if they are supported. </li> <br />
  
<li> You can click the save button, which will save the recipe to the "My Recipes" page, accessed through the right sidebar, where you can edit and delete recipes. </li> <br />
  
<li> From the sidebar, you can also access the "All Recipes" page, which has cards for every base recipe registered, and you can remove them or edit them from the same page. </li> <br />
  
<li> Another page accessed from the right sidebar allows you to Add custom items by uploading images and giving their properties. </li> <br />
<li> The left sidebar is where you can export the scripts, to be placed in the "instance/KubeJS/server-scripts" folder of your minecraft instance. </li> <br />
</ul>
